# Codex Prompt — Implement One Task

```text
Read AGENTS.md and the assigned task file: <TASK_PATH>.
Also read every dependency, ADR, schema, and documentation file referenced by that task.
Inspect the repository before editing.

Implement only this task. Do not start dependent or adjacent tickets.
Before coding, give a compact plan and name the files/modules likely to change.
During implementation:
- preserve all security/privacy and outbound-only architecture rules;
- use deterministic time in timing-sensitive tests;
- add automated tests for every material behavior;
- update schemas/docs/ADRs when the task changes a contract or architecture decision.

Run the task-specific commands and the repository-wide test command.
Then provide the AGENTS.md completion report, including criterion-by-criterion status.
```
